# Стенд и e2e-тесты TopTeam

Стенд — **локальная** копия бэкенда: Supabase в Docker (Colima) со всеми миграциями из `supabase/migrations/` и выдуманными людьми. Фронтенд — `vite dev` на :5186, направленный на стенд. Прод не используется никогда (в `fixtures/app.ts` стоит предохранитель: запрос к `*.supabase.co` или `topteam-kl7.pages.dev` роняет тест).

## Команды

```bash
cd e2e && npm ci                 # первый раз
npm run stand                    # поднять Supabase (и Colima, если выключен), сбросить базу, наполнить
npx playwright test              # все тесты (сам поднимет стенд и фронтенд, если надо)
npx playwright test tests/<feature>
npx playwright show-report       # отчёт: e2e/playwright-report/
npx supabase@3.1.0 stop          # (из корня репо) остановить стенд; `colima stop` — выключить Docker
```

Браузер — системный Google Chrome (`channel: 'chrome'`), скачивать браузеры Playwright не нужно. Все тесты — в мобильном виде (`Pixel 7`).

## Помощники (`fixtures/app.ts`)

- `loginAs(page, role, path)` — вход без Telegram: сессия по паролю стенда кладётся в localStorage.
- `rpc(role, fn, args)` — вызвать RPC от имени роли (проверка `forbidden` на уровне API).
- `expectNoHScroll(page)` — нет горизонтального скролла.
- `test`, `expect` — импортировать отсюда, а не из `@playwright/test` (в них предохранитель от прода).

Шаблон теста роли — `templates/role.spec.ts`. Имена тестов — `AC-n: …` из спеки.
