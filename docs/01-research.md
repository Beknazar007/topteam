# Фаза 0 — Исследование

## Главный конкурент — не приложение, а доска в зале
Сейчас в зале результаты пишут маркером на доске или в тетради. Проблемы:
- Доску стирают → история и рекорды теряются.
- Нет прогресса: «сколько я делал Fran полгода назад?» — неизвестно.
- Нет мотивации между тренировками: результат виден только тем, кто был в зале в этот час.
- Тренер не видит картину по группе.

**Задача MVP: сделать записать результат в телефон быстрее и приятнее, чем маркером на доске.**

## Анализ конкурентов

| Продукт | Что делает хорошо | Слабые стороны для нас | Что берём |
|---|---|---|---|
| **SugarWOD** | Цифровая «доска» зала, WOD от тренера, fist bumps, лидерборд, бенчмарки | Нет русского, нет геймификации, западный UX, платит зал | Модель «зал → WOD → доска», fist bump |
| **Wodify** | Полное управление залом: оплаты, запись на классы, трекинг | Тяжёлый, дорогой, ориентирован на владельца, а не на атлета | Пока ничего (управление залом — не наш MVP) |
| **BTWB (Beyond the Whiteboard)** | Глубокая аналитика, «уровень фитнеса» по навыкам | Сложный, перегруженный интерфейс, порог входа | Радар навыков (v2), автоопределение PR |
| **Strava** (эталон соцсети) | Kudos, лента, клубы, челленджи, сегменты, шеринг | Не про кроссфит | Механика ленты, kudos, челленджи, красивые карточки |
| **Duolingo** (эталон геймификации) | Серии, заморозка серии, XP, лиги | Не про спорт | Streak + freeze, XP, лиги (v2) |
| **Telegram/WhatsApp-чат зала** | Все уже там, ноль трения | Результаты тонут в чате, нет статистики | Вход через Telegram, шеринг в чат зала |

## Наше отличие
1. **Русский язык и локальный рынок** — у западных продуктов его нет.
2. **Telegram-first**: вход в один клик, карточка результата сразу в чат зала → бесплатный маркетинг.
3. **Геймификация** (XP, уровни, серии, бейджи) — у кроссфит-трекеров её почти нет.
4. **Бесплатно и без установки** (PWA) — порог входа минимальный.
5. **Скорость**: запись результата за ~10 секунд.

## Ценностное предложение
> **TopTeam — цифровая доска твоего зала: записывай результат за 10 секунд, бей личные рекорды, качай уровень и соревнуйся с залом.**

## Риски и как их снизить
| Риск | Решение |
|---|---|
| Весь объём «всё сразу» за 1 месяц в одиночку | Жёсткий MVP: лента = автоматические посты из результатов (без фото), игра = XP/уровни/серии/бейджи; лиги, челленджи, чат — в v2 |
| Атлеты забудут открыть приложение | Тренер публикует WOD → уведомление; серия (streak) мотивирует возвращаться |
| Тренер не захочет вводить WOD | Сделать ввод WOD за 1 минуту, шаблоны бенчмарков; первое время WOD может вводить автор |
| Push-уведомления в PWA на iOS ограничены | Дублировать уведомления через Telegram-бота (бесплатно) |
| Накрутка результатов | Пока доверие внутри одного зала + тренер может отметить/скрыть результат |
| Лимиты бесплатных тарифов | Без медиа в MVP — нагрузка минимальная, одного зала хватит с запасом |
