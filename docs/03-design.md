# Фаза 2 — Дизайн

Кликабельный прототип: [prototype/index.html](prototype/index.html) (открыть в браузере; на компьютере — в рамке телефона).

## 1. Визуальный стиль
- **Настроение:** энергия, «огонь», спортзал вечером. Тёмная тема по умолчанию.
- **Шрифт:** Inter (кириллица, цифры моноширинные через `tabular-nums` — важно для времени и весов).
- **Цвета (токены):**

| Токен | Цвет | Назначение |
|---|---|---|
| `bg` | `#0B0C0F` | фон |
| `surface` / `surface2` | `#15171C` / `#1E2128` | карточки / поля |
| `accent` | `#FF6B2C` | главный цвет бренда, кнопки, 🔥, серия |
| `xp` | `#3DDC84` | опыт, прогресс |
| `gold` | `#FFC83D` | личные рекорды, 1-е место, легендарные бейджи |
| `blue` / `purple` | `#4DA3FF` / `#B07CFF` | редкие / эпические бейджи |
| `muted` | `#8B92A0` | второстепенный текст |

- **Награды:** конфетти при PR и новом уровне, «прибегающие» строки XP, заполнение шкалы, вибрация (`navigator.vibrate`) на телефоне.
- **Принцип:** главное действие («Записать результат») всегда в один тап — центральная кнопка в нижнем меню.

## 4. Решения, принятые в дизайне
- Отдельные доски **RX / Scaled / Beginner** и **М / Ж** — новички соревнуются с равными.
- В ленте только 🔥 (без дизлайков и без счётчика подписчиков) — атмосфера поддержки.
- Серия показывается точками недели, а не огромным числом — меньше давления на новичков.
- Карточка шеринга — вертикальная (9:16) под сторис Instagram и превью в Telegram.
