## 1. Персоны

| Персона | Кто | Цель | Боль | Что зацепит |
|---|---|---|---|---|

## 2. Пользовательские пути

**Онбординг атлета (цель: < 60 секунд)**
QR-код на стене зала → открывается TopTeam → «Войти через Telegram» → автоматически вступает в зал → выбирает пол и уровень (Beginner/Scaled/RX) → видит WOD дня → бейдж «Добро пожаловать» (+XP, сразу дофамин).

**Ежедневный путь атлета**
Уведомление в Telegram «WOD дня опубликован» → смотрит WOD → тренируется (по желанию — таймер в приложении) → «Записать результат» (≤ 10 сек) → анимация XP / PR / бейджа → видит место в лидерборде → делится карточкой в чат зала → вечером получает 🔥 и комментарии → возвращается в приложение.

**Путь тренера**
Вечером/утром: «Новый WOD» → выбирает формат (For Time / AMRAP / …) → вводит упражнения или выбирает бенчмарк → публикует → днём смотрит лидерборд, ставит 🔥, может скрыть ошибочный результат.

## 4. Игровая экономика

### 4.1 Начисление XP
| Действие | XP | Ограничение |
|---|---|---|
| Записать результат WOD дня | **50** | до 2 тренировок в день |
| Записать личную тренировку (v1.1) | 30 | входит в лимит выше |
| Уровень RX / Scaled / Beginner | +10 / +5 / +5 | — |
| Бенчмарк (Girls/Hero) | +20 | — |
| Новый PR | **+50** | до 3 PR в день |
| Первый результат в бенчмарке (baseline) | +15 | — |
| Топ-3 лидерборда WOD (в своей категории) | +20 / +15 / +10 | начисляется в конце дня |
| Бонус серии | +5 × недель серии | максимум +40 за тренировку |
| Поставить 🔥 | +1 | до 10 в день |
| Написать комментарий | +2 | до 5 в день |
| Получить бейдж | по редкости: 25 / 75 / 200 / 500 | — |

> Принцип: **~90% XP — за тренировки**, соцдействия дают мало и с лимитами, чтобы нельзя было «накликать» уровень. Отдельные доски RX/Scaled/Beginner, чтобы новички тоже попадали в топ-3.

### 4.2 Уровни
**Формула:** XP для достижения уровня L = `50 × (L − 1)²`

| Уровень | Всего XP | Примерно когда (≈4 трен./нед ≈ 300 XP/нед) | Титул |
|---|---|---|---|
| 2 | 50 | первая тренировка | Новичок (1–4) |
| 5 | 800 | ~3 недели | Атлет (5–9) |
| 10 | 4 050 | ~3,5 месяца | Боец (10–14) |
| 15 | 9 800 | ~8 месяцев | Ветеран (15–19) |
| 20 | 18 050 | ~1,2 года | Зверь (20–29) |
| 30 | 42 050 | ~2,7 года | Легенда (30+) |

**Проверка баланса:** первые уровни приходят быстро (крючок в первые недели), дальше — замедление, но всегда есть ближайшая цель (бейдж/серия). Уровень 30+ — статус для «старичков» зала.

### 4.3 Серия (streak)
- Серия **недельная**, а не ежедневная: в кроссфите нужны дни отдыха, ежедневная серия поощряла бы перетренированность.
- Атлет выбирает цель: **2, 3, 4 или 5 тренировок в неделю** (по умолчанию 3). Неделя Пн–Вс выполнена → серия +1.
- **Заморозка:** 1 заморозка за каждые 4 выполненные недели, хранится максимум 2. Если неделя не выполнена и есть заморозка — она тратится автоматически, серия сохраняется.
- Напоминание в Telegram в пятницу/субботу: «Осталась 1 тренировка до сохранения серии 🔥 12 недель».

### 4.5 Лиги (v2, черновик)
Ежемесячный сезон по XP внутри зала: Бронза → Серебро → Золото → Элита. Топ-20% повышаются, нижние 20% понижаются. Отдельный рейтинг по проценту выполнения серии, чтобы новички тоже могли побеждать.

## 5. Метрики успеха (зал-тестер, первые 30 дней после запуска)

| Метрика | Цель |
|---|---|
| Доля активных членов зала, зарегистрировавшихся | ≥ 60% за 2 недели |
| Доля тренировок, по которым записан результат | ≥ 50% |
| Удержание D1 / D7 / D30 | 60% / 45% / 35% |
| WAU / зарегистрированные | ≥ 50% |
| Тренер публикует WOD | ≥ 90% тренировочных дней |
| Шеринг карточек | ≥ 10% результатов |
| Время записи результата (медиана) | ≤ 15 сек |

Инструмент: события в собственной таблице БД + бесплатный PostHog (решим в Фазе 3).
